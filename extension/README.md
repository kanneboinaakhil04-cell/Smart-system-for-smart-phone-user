# 🛡️ PhoneBalance Chrome & Edge Extension Companion

This browser extension provides real-world **One-Sec Mindful Interception**:
- Automatically intercepts when you open **YouTube, Instagram, Reddit, Twitter/X, TikTok, or Netflix**.
- Pauses the page with a 7-second mindful breathing circle.
- Prompts for intention (Habit, Boredom, Tutorial, Urgent Message).
- Automatically records telemetric screen time and aborted opens back to the PhoneBalance backend.

---

## 🚀 How to Install in 10 Seconds:

1. Open **Google Chrome** (or Edge / Brave) and navigate to:
   ```
   chrome://extensions
   ```
   *(or `edge://extensions` in Microsoft Edge)*

2. In the top right corner, toggle **Developer mode** to **ON**.

3. Click the **Load unpacked** button in the top left.

4. Select the `extension/` folder inside this project:
   `c:\Users\Akhil\OneDrive\Desktop\Smart system for smart phone user\extension`

5. Done! The PhoneBalance shield icon will appear in your browser extensions bar. Try visiting [youtube.com](https://www.youtube.com) to experience the mindful breathing friction in action!
